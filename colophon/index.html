How this site is made. Plain HTML, hand-written CSS and small ES modules - no framework, no build step, no tracker.

01

Principles

Every page is a static file. A server sends it, and a browser shows it. No build step stands between the source and the site.

The site loads no code from an other domain. There is no tracker, no analytics script and no cookie.

Each page works without JavaScript. A script only adds comfort: the theme button, the menu on a small screen, the copy button and the filter.

02

Type

Three families set the text. Archivo sets the display lines. Source Serif 4 sets the body. IBM Plex Mono sets the labels and the numbers.

The font files are subset to the Latin range. All seven files weigh about 238 KB together, and a page loads only the faces it uses.

03

Color

The colors live in custom properties in one file. The light theme is navy text on cool paper, with an Imperial Blue accent.

The dark theme keeps the hue and lifts the accent, because pure blue is too dark on a dark ground.

A small script applies your stored choice before the first paint, so the page does not flash. Without the script, the page follows the device.

04

Motion

The moving backgrounds are hand-written canvas scenes: streamlines from potential flow, a vortex street, a beam in its modes, a craft on a coastline.

A scene stops when it leaves the screen, when the tab goes to the back, or when you ask for reduced motion or reduced data. A pause button on each field stops it by hand.

The lab runs the same scenes with controls.

05

Weight

The home page is about 90 KB of HTML, CSS and JavaScript. With every font it moves about 330 KB.

There is no dependency to update and no lockfile. The full source is the site itself.
